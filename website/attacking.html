Module 02

How Attackers Exploit Authentication

Kerberos and NTLM contain design-level weaknesses that adversaries have turned into reliable, repeatable attack techniques against AD environments.

Primary Attack Techniques

password

Password Spraying & Brute Force

T1110

Brute force targets one account with many passwords; spraying tries one password across many accounts to stay under lockout thresholds.

Event IDs to watch: 4625 (failed logon) · 4740 (account lockout) · 4771 (Kerberos pre-auth failure)
vpn_key

Kerberoasting

T1558.003

Any domain user can request a TGS for any SPN-registered account. The ticket is encrypted with the service account's hash — exportable and crackable offline with no network noise.

Event IDs to watch: 4769 (Kerberos service ticket request with RC4 encryption type 0x17)
fingerprint

Pass-the-Hash (PtH)

T1550.002

NTLM authenticates with a hash, not plaintext. Attackers dump hashes from memory (e.g., Mimikatz) and use them directly to move laterally — no cracking needed.

Event IDs to watch: 4624 Logon Type 9 (NewCredentials) — explicit credential use over NTLM
hub

AS-REP Roasting

T1558.004

Accounts with preauthentication disabled respond to AS-REQ without verifying identity. Attackers request the AS-REP and crack the encrypted blob offline.

Event IDs to watch: 4768 with preauth type 0 — AS-REQ without preauthentication

Real-World Incidents (2023–2025)

These are not theoretical. Every technique above was used in a real breach.

APT29 · 2024

Midnight Blizzard

Russian state actor used password spraying against legacy test accounts that lacked MFA to breach Microsoft corporate email systems. The accounts had never been secured because they were "non-production."

Technique: T1110.003
UNC3944 · 2024

Change Healthcare

Attackers used stolen credentials acquired via info-stealer malware to authenticate to a Citrix remote access portal. No MFA was configured. Led to widespread ransomware deployment across healthcare systems.

Technique: T1078
ALPHV/BlackCat · 2023–24

MGM Resorts / Caesars

Used social engineering and MFA fatigue to bypass authentication, then leveraged Pass-the-Hash for lateral movement through the AD environment. Demonstrated that even MFA can be bypassed at the human layer.

Technique: T1550.002
