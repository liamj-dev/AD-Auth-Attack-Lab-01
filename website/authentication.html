Module 01

What Is Authentication?

Authentication is the process of verifying that an entity — a user, device, or service — is who it claims to be. In enterprise environments, Active Directory acts as the central identity authority for all authentication decisions.

The Three Authentication Factors

Robust authentication combines multiple factors. Relying on a single factor — especially passwords — is the primary root cause of compromise in real-world breaches.

RISK: Most AD environments rely solely on passwords (Factor 1). The attacks in this lab exploit exactly that weakness.

Key Protocols in Active Directory

key
Kerberos
Ticket-based. Default for AD since Windows 2000. Uses the KDC (Key Distribution Center) on the Domain Controller.
vpn_key
NTLM
Challenge-response fallback. Used when Kerberos is unavailable. Older and weaker — still widely supported, which is the problem.
account_tree
LDAP
Lightweight Directory Access Protocol. Used to query and modify AD directory data — user accounts, groups, policies.
api
OAuth 2.0
Token-based delegation for cloud and web services. Used in hybrid environments alongside traditional AD auth.
